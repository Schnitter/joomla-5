# Joomla 5 – Bootstrap 5 Integration

## 🇩🇪 Deutsch

Dieses Repository enthält Erweiterungen für **Joomla! 5.x**, die die Integration von **Bootstrap 5** erleichtern.
Es umfasst ein Modul und ein System-Plugin, die speziell für die Nutzung von Bootstrap 5 entwickelt wurden.

### 📦 Enthaltene Erweiterungen

* **mod\_vtc-bootstrap5**:
  Ein Joomla-Modul, das die Integration von Bootstrap 5 in Joomla! 5.x ermöglicht.

* **plg\_system\_vtc-bootstrap5**:
  Ein System-Plugin, das zusätzliche Funktionen und Anpassungen für die Verwendung von Bootstrap 5 bereitstellt.

## 🇬🇧 English

This repository contains extensions for **Joomla! 5.x** that facilitate the integration of **Bootstrap 5**.
It includes a module and a system plugin specifically designed for using Bootstrap 5.

### 📦 Included Extensions

* **mod\_vtc-bootstrap5**:
  A Joomla module that enables Bootstrap 5 integration in Joomla! 5.x.

* **plg\_system\_vtc-bootstrap5**:
  A system plugin that provides additional features and adjustments for using Bootstrap 5.
